# 漫剧工坊 · AI 漫剧剧本一键生成

输入脑洞灵感 / 小说原文 / 旧分镜脚本，一次输出整套漫剧生产素材。

## 怎么用

1. 双击 `启动.bat`（会自己打开 http://127.0.0.1:5178）
2. 右上角「模型配置」填一套 OpenAI 兼容接口：
   - DeepSeek：`https://api.deepseek.com/v1` + `deepseek-chat`
   - 通义千问：`https://dashscope.aliyuncs.com/compatible-mode/v1` + `qwen-plus`
   - Kimi：`https://api.moonshot.cn/v1` + `moonshot-v1-32k`
   - 也有「快速填入」按钮，点一下就填好地址和模型，只需补 Key
3. 左侧填素材 → 选风格/画幅/时长 → 「生成整套漫剧素材」

没配 Key 也能玩：点「先看示例成品」，看完整交付标准（内置一份 10 镜的《第七次末班车》全案）。

## 输出什么

固定六块，按序交付：

| 区块 | 内容 |
|---|---|
| 剧情简介 | 主人公、核心人设、完整剧情走向 |
| 角色三视图提示词 | 16:9 白底 turnaround，正向 + 反向负面分列 |
| 场景图提示词 | 同上 |
| 关键道具图提示词 | 同上 |
| 分镜剧本 | 每镜 9 项：机位/运镜、构图、画面内容、微表情&动作细节、光影、特效、音色、台词、音效 |
| 镜头禁止项清单 | 穿模、崩脸、道具篡改、色温跳变、塑料质感、水印、非指定台词、机械配音、视线错位等 |

## 几条内置规矩

- 不改主线剧情，只优化镜头表达、运镜、画面细节与衔接节奏
- 你给的关键台词与核心动作原样保留，只做润色细化
- 上传参考图时为每张填「空间位置」，分镜会遵守这套空间逻辑，杜绝跳轴
- 提示词一律正向 / 反向负面分开罗列

## 文件说明

```
server.js            本地服务：静态托管 + LLM 流式转发（零依赖）
启动.bat             一键启动
public/index.html    页面
public/styles.css    样式
public/app.js        逻辑（含输出解析与分镜渲染）
public/demo.js       内置示例成品
```

## 注意

- 模型配置只存在本机浏览器 localStorage，不上传任何第三方
- 必须通过 `启动.bat` 打开；直接双击 `public/index.html` 无法调用模型（浏览器跨域限制）
- 端口被占用时改端口：`set PORT=5180 && node server.js`
